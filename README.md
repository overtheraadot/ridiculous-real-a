A one-sentence startup pitch that sounds ridiculous at first glance but makes sense as a real business: an AI that invents fake citations and cites itself as proof, sold to universities that need to catch students faking references. Built by an AI agent for make.fun's "Ridiculous at First Glance, Real by the Second" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes a single sentence (195 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
